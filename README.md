## Featured work

### Credit Risk Decision Lab

An explainable credit-risk research project using the UCI Taiwan credit-card dataset. It combines a 20-feature random forest with model validation and an interactive decision workspace.

- Explore synthetic account scenarios and estimated default probabilities.
- Examine the trade-off between risk thresholds and classification outcomes.
- Study how a limited review capacity concentrates observed defaults in the historical test set.

On the 6,000-account test sample, the model achieved **0.7741 ROC-AUC**; reviewing the highest-risk 10% captured **31.27%** of observed defaults. Full-dataset exploration preceded the split, limiting test-set independence. The dashboard is for historical research, not real lending decisions.

[Interactive dashboard](https://huanzhenyang0125-cyber.github.io/default-credit-card-prediction/) · [Research, report and code](https://github.com/huanzhenyang0125-cyber/default-credit-card-prediction)
